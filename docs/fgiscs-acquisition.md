# Управляемый сбор данных ФГИС ЦС

## Что уже работает

Система получает по точному коду КСР публичную запись ФГИС ЦС и сохраняет не
только результат разбора, но и все четыре сырых JSON-ответа: субъект, ценовую
зону, период и найденный ресурс. Каждый ответ и общий канонический манифест
записываются в контент-адресуемое хранилище с SHA-256 и полностью
воспроизводятся до регистрации результата.

До сетевого запроса система фиксирует хэш контекста. После запроса она повторно
проверяет:

- версию и состояние проекта;
- подтверждённый комплект документов и его хэш;
- утверждённую политику `fgis_cs_acquisition_policy`;
- квалификацию изолированного SYSTEM-адаптера;
- текущее проверенное сопоставление номенклатуры;
- точную строку ВОР, единицу и код ресурса в запросе.

Изменение любого основания останавливает запись. На экране ценовой позиции
показываются рядом исходное название ВОР и официальное название ФГИС ЦС,
единицы, точные строковые значения источника, ссылка, время получения и хэши.

## Настройка

Необходимо указать полную тройку настроек:

```dotenv
FGISCS_ADAPTER=<qualified-adapter-name>
FGISCS_ADAPTER_QUALIFICATION_ID=<approved-qualification-id>
FGISCS_WORKER_ACTOR_ID=<isolated-system-actor-id>
```

Частичная настройка запрещена. Квалификация должна разрешать метод
`EXTERNAL_SYSTEM`, тип источника `FGIS_CS`, точный origin из политики, нужную
организацию и тот же SYSTEM actor.

Проект должен иметь утверждённую и привязанную версию вида и назначения
`fgis_cs_acquisition_policy` со следующими полями:

```json
{
  "subject_name": "<точное название субъекта>",
  "price_zone_name": "<точное название ценовой зоны или null>",
  "period_name": "<точное название периода>",
  "allowed_project_states": ["PRICING_IN_PROGRESS"],
  "required_adapter_name": "<qualified-adapter-name>",
  "required_adapter_version": "<qualified-adapter-version>",
  "source_origin_id": "fgiscs.minstroyrf.ru"
}
```

## Запуск

```powershell
tenderguard import-governed-fgiscs-material `
  --project-id "<project-id>" `
  --item-id "<semantic-key строки ВОР>" `
  --resource-code "02.3.01.02-1102" `
  --request-id "<уникальный request-id>" `
  --reason "Получить официальное исходное доказательство для проверки"
```

Сетевой запрос и запись объектов выполняются без открытой транзакции БД. Затем
короткая транзакция повторно проверяет контекст и воспроизводит результат из
сохранённых объектов.

## Жёсткое ограничение

Полученная запись всегда имеет `UNVERIFIED`, `ready_for_pricing=false` и минимум
две блокировки: `APPROVED_FGIS_MAPPING_REQUIRED` и
`COMMERCIAL_BASIS_NOT_ESTABLISHED`. Она не создаёт `PriceQuote` и не участвует в
итоговой смете автоматически.

Не завершены утверждение методики коммерческой базы ФГИС ЦС, отдельное
сопоставление ВОР с КСР по правилу четырёх глаз и преобразование подтверждённой
записи в нормализуемое ценовое наблюдение. До этого автоматическое использование
значения в итоговой смете запрещено.
